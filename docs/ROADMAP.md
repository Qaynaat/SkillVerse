# 🚫 Things We Will NOT Build

We will NOT build:

❌ Programming courses

❌ Video lectures

❌ Certificates

❌ LMS (Learning Management System)

❌ Online university

❌ Course marketplace

❌ Coding IDE

❌ YouTube clone

❌ Coursera clone

❌ Udemy clone

----------------------------------------------------

# 🌍 Instead We Will

✓ Guide students.

✓ Explain careers.

✓ Recommend trusted learning resources.

✓ Build personalised roadmaps.

✓ Track progress.

✓ Keep students motivated.

✓ Help them never feel lost again.

----------------------------------------------------

# 💜 The Golden Rule

Whenever we think of adding a feature, ask:

"Does this help students navigate their career journey?"

If YES → Build it.

If NO → It doesn't belong in SkillVerse.
